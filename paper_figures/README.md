# Optional matplotlib exports

The submitted PDF draws figures with TikZ/pgfplots in `paper/main.tex`. Files here, if present, are **not** the manuscript and must not be cited.

`scripts/analysis/generate_paper_figures.py` can regenerate optional PNG/PDF copies from `results/reports/revision_reanalysis_report.json`. The Condition B manuscript figure is a cost-accuracy scatter with separate serving-condition panels, not a Pareto plot. Older filenames such as `figure1_pareto_frontier.*` are leftover from a retracted framing.
