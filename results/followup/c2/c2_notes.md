# C2 - overthinking-error share (CPU only; built 2026-10-22/23; read-only on all result trees)
These are PROXIES, not the model-based overthinking classification of Lotfi et al. No verdict rule has been applied here; the numbers are for the user to apply the fixed rule.
Population: every INCORRECT (extractive_match = 0), FINISHED (not stopped by the length limit: compact hit_token_limit=false, or finish_reason != length for the P2 cells) MATH-500 completion, from the stored completion text.
Scorer: the campaign's own functions (lighteval 0.8.0, env qrm-official): get_extraction_regexes / extract_target_from_pred with the latex_gold_metric targets (gold: LatexExtractionConfig; prediction: ExprExtractionConfig + LatexExtractionConfig(boxed_match_priority=0), first_match fallback, any_match, 5 s timeout) and compare_gold_target(precision 5).
P-a: some \boxed{...} expression in the trace (brace-matched; first 12 distinct expressions per trace) is equivalent to the gold answer under that extraction + comparison (each expression is re-extracted as "\boxed{...}"). Because the completion is already incorrect, such an expression cannot be the final extracted answer.
P-b: a string from the scorer's extracted gold (plus the raw gold string, max 60 chars) appears as a standalone token (no alphanumeric / '.'-digit neighbours) in the SECOND HALF of the trace. The half is defined on CHARACTERS, not tokens (approximation of "first 50% of tokens"). Numeric golds such as "2" match often, so P-b is a loose proxy.
Bootstrap: item-level, B = 10,000, numpy default_rng(0), the same item resamples for the arm and its reference; share = flagged / incorrect-finished completions pooled over the arm's seeds; with 0 flagged the percentile interval is degenerate [0, 0].
Arms: campaign BF16/FP8/AWQ-4/GPTQ-4 (both families, seeds 42-46); E1 self-AWQ Llama (ONLY seeds 45-46: the MATH-500 raw output of seeds 42-44 was overwritten by the E1b GSM8K run in the same directories, see EXPORT_NOTES of v2); E1c Llama (42-46); E2 fp16 and E3 T0.8 for both families (VERIFIED cells only, 42-46); P2 Qwen controlled AWQ-4 and GPTQ-4, calibration draws 0-2 pooled, seeds 42-44 (text from the job 107150 predictions, extractive_match and finish_reason from the v4b compact files). Reference for the P2 arms: campaign Qwen BF16 seeds 42-44; all other arms: campaign BF16 of the same family, seeds 42-46.
Files: c2_arm_table.tsv (counts, shares, 95% intervals), c2_pairwise_vs_bf16.tsv (arm minus reference, P-a and P-b, paired bootstrap, sign agreement), c2_cell_counts.tsv (per cell), c2_validation_snippets.tsv (<= 400 characters around the spot; only 16 P-a flagged completions exist in total, so all 16 are exported instead of 40 random; 40 + 40 for P-b, 40 + 40 unflagged for each proxy).
Unflagged snippets show the region of the last \boxed (P-a) or the end of the trace (P-b).
